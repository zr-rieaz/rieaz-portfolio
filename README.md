# 🚀 [My Portfolio](https://zrrieaz.vercel.app/)

Welcome to my personal portfolio repository! This site showcases my projects, skills, education, and contact details in a responsive, modern interface built with cutting-edge web technologies.

🌐 **Live Demo:** [https://zrrieaz.vercel.app/](https://zrrieaz.vercel.app/)

---

## ✨ Features

- **⚡ High Performance:** Fast loading times powered by Next.js and optimized deployment on Vercel.
- **📱 Fully Responsive:** Clean layout tailored for Mobile, Tablet, and Desktop screens.
- **🎨 Modern UI/UX:** Stylized with Tailwind CSS for smooth animations, aesthetic typography, and clean design.
- **📩 Functional Contact Form:** Direct email delivery integrated seamlessly with Formspree API.
- **🛠️ Academic & Skills Showcase:** Comprehensive breakdown of institutional details and technical expertise.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (React)
- **Styling:** Tailwind CSS
- **Language:** TypeScript
- **Deployment:** Vercel
- **Form Handling:** Formspree API
